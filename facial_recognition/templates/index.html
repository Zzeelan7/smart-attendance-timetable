ESP32-CAM Setup Guide
  1. Flash CameraWebServer sketch (Arduino IDE → Examples → ESP32 → Camera)
  2. Set board to AI Thinker ESP32-CAM
  3. Set your WiFi SSID & password in the sketch
  4. Connect IO0 to GND to enter flash mode, then disconnect after flashing
  5. Open Serial Monitor at 115200 baud — note the IP address
  6. Enter URL above as http://<IP>/stream
